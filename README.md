## 3. Recent Cybersecurity News / Incident I Read About
**The XZ Utils Supply Chain Backdoor (CVE-2024-3094)**  
Recently, I read about the sophisticated supply chain attack targeting **XZ Utils** (versions 5.6.0 and 5.6.1), a widely used lossless data compression library present in nearly all Linux distributions. A threat actor operating under the alias *Jia Tan* spent years building trust as a maintainer before injecting a stealthy backdoor into the build process. The malicious code hooked into `sshd` (OpenSSH daemon) via `systemd` and `liblzma`, allowing unauthorized remote code execution with root privileges when a specific Ed448 private key was used during SSH authentication. It was discovered by Microsoft engineer Andres Freund while investigating unusual SSH login latency and CPU usage—highlighting both the fragility of open-source supply chains and the importance of proactive security monitoring.
